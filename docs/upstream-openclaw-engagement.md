## What counts as a durable GitHub contribution

The goal is not to accumulate references to other people's PRs. The durable target is to leave a public `hippoley` artifact in the upstream chain:

1. a focused PR with a reproducible bug and bounded patch;
2. a runtime or compatibility proof attached to an upstream PR;
3. a review that finds a concrete defect or verifies a hard blocker;
4. an issue with a minimal reproduction and maintainer-usable evidence;
5. a benchmark or timing artifact that resolves an explicit review request.

When an item is merged, the record should be moved out of the active table immediately. If upstream incorporates or supersedes the work, the record should preserve that relationship without relabeling it as a merged `hippoley` PR.

## 2026-10-07 commit-overlap expiry race follow-through

- **#163138 fresh review found a new lost-wake race.** On head `fea95c9d35d6c7d605e321f51a98e74a71a77ce6`, `expireScheduled()` returns immediately when `entry.committing` is true. Because GatewayScheduler removes the one-shot job before invoking its callback, an early wall-clock wake overlapping `resolveWithCommit()` can delete the only expiry wake. If the commit then rejects before the monotonic deadline, `finally -> get(id)` leaves the question pending with no automatic future expiry. The minimal repair is to compute/re-arm remaining monotonic budget before the committing guard, while still refusing to expire at/after deadline during an active commit.
- Exact contract: `docs/patches/openclaw-163138-commit-overlap-expiry-rearm.md`, commit `e3adaa499ae56b9d5cb46a197ae6188b9119a3a0`. Exact production diff: `docs/patches/openclaw-163138-commit-overlap-expiry-rearm.patch`, commit `724658f38a6115d8739b9d46714c547df193d92a`. Upstream handoff: https://github.com/openclaw/openclaw/pull/163138#issuecomment-6032859599.
- The focused regression deliberately uses a timeout-free `waitAnswer()` and avoids any post-failure `get()`/`list()` forcing read. It proves: early wake while commit is active -> replacement job armed -> commit fails before deadline -> no forcing read -> monotonic deadline fires -> waiter receives `expired`.
